# 三维俄罗斯方块

立体的俄罗斯方块（Blockout 玩法）：井是一个立方体空间，方块不再只在平面上打转，而是可以绕三个轴翻身。填满一整层那一层就会消失。

双击 `三维俄罗斯方块.html`，用浏览器打开即可。样式、三维渲染和游戏逻辑全部在这一个文件里，**无需安装、联网或启动服务器**。三维画面是自写的投影 + 画家算法 + 面法线光照，用 Canvas 2D 绘制，不依赖任何外部库。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← → 或 A / D | 左右移动（X 轴） |
| ↑ ↓ 或 W / S | 纵深移动（Z 轴，靠近或远离镜头） |
| Q / E | 绕竖轴旋转（转身） |
| R / F | 绕横轴翻转（向前 / 向后翻） |
| Z / C | 绕前后轴滚转（侧滚） |
| Shift | 加速下落 |
| 空格 | 直接落下 |
| P / Esc | 暂停或继续 |
| Enter | 开始游戏，或从暂停中继续 |

- 在画面上拖动可以转动镜头，滚轮缩放，右上「重置视角」回到默认机位。
- 「自动旋转」让镜头缓慢环绕，方便观察被挡住的角落。
- 窄屏和触屏设备显示操作按钮，移动键支持长按连发。
- 切换窗口或隐藏页面时自动暂停。

## 井的大小

在开始界面（暂停、结束画面同样可见）可以选择三档，选择会记在浏览器里：

| 档位 | 尺寸 | 每层格数 | 说明 |
| --- | --- | --- | --- |
| 小 | 5 × 5 × 12 | 25 | 最紧凑，消层最快，也最容易顶到井口 |
| **中（默认）** | **6 × 6 × 16** | **36** | 活动空间与容错都明显更宽裕 |
| 大 | 7 × 7 × 20 | 49 | 最宽松，但每层格数多，消层最慢 |

井越大，方块可挪腾的余地越多、离井口越远，越不容易被顶死；但每层要填的格子也更多，消层来得更慢。中途切换尺寸会直接开新的一局（棋盘几何变了，没法沿用）。

## 规则

- 一整层（小 25 / 中 36 / 大 49 格）全部填满才会消除。
- 方块从井口上方进场。若落定时有格子还在井口之外，判定为井满，游戏结束。
- 12 种立体方块随机出现（单格、直条、角形、L 形、平板、T 形，以及立体的阶梯、三脚架、拐角、缺角立方体等），用加权随机抽取。
- 一次消除 1 至 5 层分别得 100、300、600、1000、1500 基础分，再乘以当前等级。
- 每消除 5 层提升一级，下落速度逐步加快；每层起始 1.38 秒，之后按 0.875 递减，最快不低于 0.19 秒（立体判断比平面费神，所以起点慢、加速也平缓）。
- 加速下落每格 1 分，直接落下每格 2 分。
- 落点有半透明幻影提示，地面另有投影。
- 落地后有约 0.56 秒的宽限期，期间还能微调位置；旋转带边缘位置调整（墙踢）。
- 最高分保存在当前浏览器本地；若浏览器禁止存储，游戏仍可正常运行。

## 画面与视角

- 井体绘制地面网格、后侧两面淡墙、四根角柱和每四层一道的箍线，用于判断纵深。
- 相机按视口自动取景：会计算让整口井（含井口上方一格的进场区）恰好落入画面的机位距离，因此桌面宽屏、竖屏和手机窄屏都不会裁切或过小。
- 立方体按相机深度排序后绘制（画家算法），并按面法线做明暗；六面都被填满的方块从井外任何角度看都不可见，会直接跳过绘制，大井里能省下大量开销。
- 消层时有约 0.32 秒的白色闪烁；系统启用「减少动态效果」时缩短为 0.09 秒。

## 音效

开始、旋转、落地、消层和结束时播放轻量合成音效，无需音频文件或联网。点击「音效：开 / 关」可切换静音，设置保存在当前浏览器；音频在首次键盘或触摸操作后启用，不支持音频时仍可正常游戏。

## 验证

用 Node 抽出 HTML 内的脚本、套一个假 DOM 执行，因此测的是真实文件而非副本。

```
node tests/logic.cjs     # 129 项断言：旋转不变量、碰撞、消层、计分、升级、结束、尺寸切换、模糊测试
node tests/render.cjs    # 录制真实绘制指令 → 自行光栅化 → 输出 PNG（可加 --next / --spawn / --size=）
```

- 旋转不变量：12 种方块 × 3 个轴，各转 4 次都能复原，正反旋转互相抵消，且旋转后仍归一化到原点。
- 消层：填满整层后正确移除、计分，且上方的方块随之整层下落。
- 升级与计分：连消 5 层后等级变为 2，首级每层 100 分。
- 结束判定：真跑主循环，井满后落定即结束。
- 尺寸切换：三档尺寸的边界、索引函数与网格容量都正确，切换会清空棋盘。
- 模糊测试：1500 帧随机操作，无异常、无越界写入、分数始终有效。
- 渲染检查：`tests/截图/` 下的图即由 `tests/render.cjs` 生成，用于目视核对三维投影、遮挡与取景（开局、中局、小 / 中 / 大井、宽屏、下一块面板）。

尚未在真实浏览器与触屏设备上实测，实际手感、音色与高分屏表现仍需人工确认。
